# Seller Intelligence

**AI-powered e-commerce platform for Malaysian sellers on Shopee, Lazada, and TikTok Shop — 5 AI agents, 30+ tools, one file**

Seller Intelligence is a self-contained web app that puts AI to work across every part of your online store. It generates product listings in 8 seconds, builds full Facebook ad campaigns, audits your store health, calculates real profit margins, and tracks competitor pricing — all inside a single HTML file with zero installation. Powered by Groq AI (free) and built for the Malaysian market.

## Why Seller Intelligence?

Running a Malaysian online store means writing listings in two languages, guessing at ad budgets, pricing blind against hundreds of competitors, and spending hours on content a customer skips in 3 seconds. Seller Intelligence replaces all of that. One tool covers listings, ads, analytics, growth forecasting, and brand content — for less than what a single freelance listing writer charges per month.

## Quick Start

No installation. No server. No backend.

1. Open `seller Ai- V4.0.html` in any browser
2. Get a free Groq API key at [console.groq.com/keys](https://console.groq.com/keys) — sign up free, no credit card
3. Click **AI Setup** at the top of the app and paste your key (starts with `gsk_`)
4. Type any product name and click **Generate** — your first listing is ready in 8 seconds

## Configuration

No `.env` file or server needed. All settings live in your browser's `localStorage`.

| Setting | Where | Description |
|---|---|---|
| `Groq API Key` | AI Setup button | Free key from [console.groq.com/keys](https://console.groq.com/keys) — powers all AI features |
| `License Key` | Activate Key tab | Pro license key received after payment — format `SINV-XXXX-XXXX-XXXX-XXXX` |
| Payment via ToyyibPay | Upgrade modal | FPX, Maybank2u, CIMB Clicks, and all Malaysian banks |
| Payment via bank transfer | Upgrade modal | Manual transfer + WhatsApp receipt to receive license key |

AI providers used: **Groq** (primary, free tier available) · **Google Gemini** (fallback)
